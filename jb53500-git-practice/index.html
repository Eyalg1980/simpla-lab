תרגיל 1

פקודות בטרמינל

יוצרים תיקייה בסייר הקבצים, ומשם הכל רק בפקודות: לנוע בין תיקיות, ליצור, להציג ולמחוק.

0בעזרת סייר הקבצים, צרו תיקייה בשם games, ופתחו טרמינל+

על שולחן העבודה: קליק ימני, New (חדש), Folder (תיקייה), ושם התיקייה games.

פותחים טרמינל: לוחצים על Start, מקלידים Git Bash ולוחצים Enter.

על שולחן העבודה: קליק ימני, New Folder, ושם התיקייה games.

פותחים טרמינל: Cmd ורווח יחד, מקלידים Terminal ולוחצים Enter.

מכאן ועד סוף התרגיל, רק פקודות. לא נוגעים בסייר הקבצים.

אהגיעו לתיקייה games+

נכנסים לתיקייה games שעל שולחן העבודה, ובודקים איפה אנחנו:

cd ~/Desktop/games
pwd

אמור להופיע: שורה שמסתיימת ב-/Desktop/games.

לא עובד: מופיע No such file or directory? ב-Windows שולחן העבודה יושב לפעמים בתוך OneDrive. כתבו cd ורווח, גררו את התיקייה games מסייר הקבצים לתוך החלון, ולחצו Enter.

בעלו תיקייה אחת למעלה+ 
cd ..

שתי הנקודות הן "התיקייה שמעליי". עכשיו אתם בשולחן העבודה.

גהציגו את כל הקבצים והתיקיות+ 
ls

אמור להופיע: הרשימה של מה שיש על שולחן העבודה, וביניהם games.

טיפ: ls -a מציג גם קבצים נסתרים, אלה ששמם מתחיל בנקודה.

דנקו את הטרמינל+ 
clear

המסך מתנקה. שום קובץ לא נמחק.

טיפ: קיצור מקלדת: Ctrl ו-L.

ההיכנסו שוב לתיקייה games+ 
cd games

אנחנו כבר בשולחן העבודה, ולכן מספיק השם של התיקייה, בלי כל הדרך.

וצרו תיקייה חדשה בשם chess+ 
mkdir chess

mkdir הוא קיצור של make directory, צור תיקייה.

זהיכנסו לתיקייה chess+ 
cd chess
חצרו קובץ בשם moves.txt+ 
touch moves.txt

touch יוצר קובץ ריק. אם תפתחו עכשיו את סייר הקבצים, תראו אותו שם.

טעלו תיקייה אחת למעלה+ 
cd ..

חזרתם לתיקייה games.

יצרו קובץ בשם game.log+ 
touch game.log
יאהציגו את כל הקבצים והתיקיות+ 
ls

אמור להופיע: chess ו-game.log.

יבמחקו את התיקייה chess+ 
rm -r chess

-r אומר: התיקייה וכל מה שבתוכה, כולל moves.txt.

זהירות: בטרמינל אין סל מחזור ואין "האם אתם בטוחים". בודקים את השם פעמיים לפני Enter.

יגמחקו את הקובץ game.log+ 
rm game.log
ls

אמור להופיע: אחרי ls לא מופיע כלום. התיקייה games ריקה.

ידנקו את הטרמינל+ 
clear
טוהריצו פקודת יציאה+ 
exit

החלון נסגר. זה הסוף של תרגיל 1.

סיימתם כש

עברתם את כל הסעיפים, והתיקייה games ריקה.

תרגיל 2

Snake ב-GitHub Pages

מעלים אתר של משחק הנחש ל-GitHub Pages, כך שכל אחד יוכל לגלוש אליו ולשחק.

אהורידו את התיקייה למחשב+
הורדה: Snake.zip

בתיקייה Downloads: קליק ימני על Snake.zip, Extract All (חילוץ הכל), ו-Extract בלי לשנות כלום.

בתיקייה Downloads: לחיצה כפולה על Snake.zip. אם Safari כבר פתח אותו לבד, מדלגים.

אמור להופיע: בתוך Downloads יש תיקייה בשם Snake, ובה שלושה קבצים: index.html, main.js ו-styles.css.

בפתחו Git Bash Terminal כך שיצביע על התיקייה+

פותחים את התיקייה Snake בסייר הקבצים, קליק ימני על שטח ריק, ובוחרים Open Git Bash here. ב-Windows 11 זה מסתתר תחת Show more options.

פותחים Terminal.

בכל מקרה, מריצים את שלוש הפקודות האלה כדי להיות בטוחים שאתם בתיקייה הנכונה:

cd ~/Downloads/Snake
pwd
ls

אמור להופיע: pwd מסתיים ב-Snake, ו-ls מציג את שלושת הקבצים.

גצרו Local Repo חדש+ 
git init -b main

אמור להופיע: Initialized empty Git repository. נוצרה תיקייה נסתרת בשם .git, ושם Git שומר את כל הגרסאות.

טיפ: -b main קובע שהענף הראשי ייקרא main, כמו ב-GitHub.

דצרו גרסה ראשונה+ 
git add .
git commit -m "First version"
git log --oneline

add . מכניס את כל הקבצים לפריים. commit מצלם, עם משפט שמסביר מה בצילום.

אמור להופיע: בסוף, שורה אחת: קוד קצר ואחריו First version.

+Author identity unknown, או Please tell me who you are

Git לא יודע מי אתם. מריצים פעם אחת, עם השם והמייל שלכם, ואז שוב את ה-commit:

git config --global user.name "Your Name"
git config --global user.email "your.course@gmail.com"
הב-GitHub, צרו Repo הנקרא Snake+
  1. נכנסים ל-github.com ומתחברים
  2. למעלה בצד ימין: +, ואז New repository
  3. ב-Repository name כותבים Snake
  4. מסמנים Public
  5. לא מסמנים Add a README file
  6. לוחצים Create repository

למה Public: ריפו ציבורי הוא תנאי ל-GitHub Pages בחינם. לכן אף פעם לא שמים בו סיסמה או מפתח API.

ובצעו Push מה-Local Repo ל-GitHub Repo+

חוזרים לטרמינל. הפקודה הראשונה מחברת את הריפו המקומי לריפו ב-GitHub, והשנייה מעלה:

git remote add origin https://github.com/YOUR-USERNAME/Snake.git
git push -u origin main

בפעם הראשונה נפתח חלון התחברות ל-GitHub. בוחרים Sign in with your browser, ומאשרים בדפדפן.

אמור להופיע: כמה שורות, ובסופן [new branch] ו-main.

+error: src refspec main does not match any

הריפו נוצר בלי -b main, והענף נקרא master. משנים את השם ומעלים שוב:

git branch -M main
git push -u origin main
+remote origin already exists

כבר חיברתם כתובת קודם. מחליפים אותה בנכונה:

git remote set-url origin https://github.com/YOUR-USERNAME/Snake.git
git push -u origin main
+rejected, fetch first

הריפו ב-GitHub נוצר עם README. מושכים אותו קודם, ואז מעלים:

git pull --rebase origin main
git push -u origin main
+ב-Mac: מבקש Username ו-Password

הסיסמה הרגילה של GitHub לא עובדת כאן. הכי פשוט: פותחים את GitHub Desktop, File, Add Local Repository, בוחרים את התיקייה, ולוחצים Push origin.

זבדקו שאכן קבצי האתר קיימים ב-GitHub Repo+

מרעננים את עמוד הריפו ב-GitHub:

https://github.com/YOUR-USERNAME/Snake

אמור להופיע: שלושת הקבצים, index.html, main.js ו-styles.css, ולידם First version.

טיפ: index.html חייב לשבת ישר בריפו, לא בתוך תיקייה. אחרת GitHub Pages לא ימצא את האתר.

חבצעו פריסה של האתר ל-GitHub Pages+
  1. בעמוד הריפו: Settings, בשורה העליונה
  2. בתפריט מימין או משמאל: Pages
  3. תחת Build and deployment, ב-Source: Deploy from a branch
  4. ב-Branch: main, ולידו / (root), ואז Save
  5. מחכים דקה או שתיים ומרעננים

אמור להופיע: למעלה בעמוד: Your site is live at, עם כתובת ועם כפתור Visit site.

טבדקו שהמשחק באוויר ושניתן לשחק בו גם מהמחשב וגם מהנייד+

הכתובת של האתר שלכם:

https://YOUR-USERNAME.github.io/Snake/

  • במחשב: משחקים עם החיצים או עם WASD.
  • בנייד: שולחים לעצמכם את הקישור בוואטסאפ, פותחים, ומשחקים בהחלקה על המסך.

לא עולה: מופיע 404? מחכים עוד דקה ומרעננים. אם עדיין, בודקים ש-index.html נמצא ישר בריפו.

סיימתם כש

הקישור https://YOUR-USERNAME.github.io/Snake/ פותח את המשחק, גם במחשב וגם בטלפון.
