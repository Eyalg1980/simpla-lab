גרסאות ב-Git

איך שינוי קטן עובר מהמפתח ללקוח, על ריפו אמיתי ב-GitHub. צפו בסרטון, ואז פתחו את הריפו ועקבו אחרי אותו סיפור בעצמכם.

להתנסות הריפו מהסרטון, פתוח לכולם github.com/eyalg1980/git-versions-demo
1Branchesשלושה ענפים: main, staging ו-dev 2Tagsחמש תגיות, מ-v1 ועד v3.1 3Commitsכל ההיסטוריה של main, כולל שני המיזוגים 4Pull requestsשתי בקשות המיזוג, סגורות 5Releasev3.1, הגרסה האחרונה
