# סטאק הקורס, 53500

המסמך הזה קובע באילו כלים נבנים הפרויקטים בקורס, ומה הכללים הטכניים שחלים על כולם.
הוא נקודת המוצא של מסמך הארכיטקטורה. אין לחרוג ממנו בלי סיבה שנובעת מה-PRD, ובלי לשאול אותי קודם.

## הכלים

| שכבה | הכלי | הערה |
|---|---|---|
| צד הלקוח | אתר סטטי: HTML, CSS ו-JavaScript | בלי React, בלי Next.js, בלי כלי בנייה |
| נתונים והתחברות | Supabase | למוצר בלי נתונים שמשתנים מספיק קובץ JSON בריפו |
| שכבת AI | קריאה למודל דרך n8n webhook או Supabase Edge Function | אף פעם לא ישירות מהדפדפן |
| אוטומציות | n8n | |
| אחסון האתר | GitHub Pages | ענף main, תיקיית השורש, ריפו ציבורי |
| גרסאות | Git ו-GitHub | ענף main בלבד, בלי ענפים ובלי מיזוגים |

## למה הסטאק הזה

- אין שלב בנייה. מה שכתוב בקובץ הוא מה שרץ בדפדפן, ולכן אפשר לקרוא את הקוד ולהבין אותו.
- כל הכיתה על אותם כלים, ולכן אפשר לעזור לכל אחד.
- כל רכיב מתאים לאחת משלוש השכבות: צד לקוח, לוגיקה, נתונים.

## חוק הברזל: מפתחות

הריפו ציבורי, וכל מה שנמצא בדפדפן גלוי לכל אדם. לכן:

- אין מפתח API בקוד. לא ב-JavaScript, לא ב-HTML, ולא בקובץ הגדרות בריפו.
- כל קריאה למודל או לשירות בתשלום עוברת דרך n8n webhook או Edge Function. הדפדפן פונה לכתובת הזו בלבד.
- היוצא מן הכלל היחיד הוא המפתח הציבורי של Supabase. הוא נועד לשבת בדפדפן, ומוגן בהרשאות הטבלה.

## נתונים

- טבלה מרכזית אחת, ועוד אחת לכל היותר. אם נראה שצריך שלוש, מצמצמים את המוצר.
- שמות טבלאות ושדות באנגלית, באותיות קטנות עם קו תחתון. התוכן בעברית.
- בונים את הטבלה לפני המסך.
- תמיד יש נתוני דוגמה, לפחות חמש שורות, כדי שאפשר יהיה לראות את המסך מלא.
- localStorage מותר רק לטיוטה, להעדפת תצוגה או לסל זמני. הוא לא הזיכרון של המערכת.

## הרשאות

שני תפקידים בלבד: משתמש, ובעל העסק. הכניסה של בעל העסק היא סיסמה אחת או קישור סודי. בלי מערכת הרשמה, בלי משתמשים מרובים, בלי שחזור סיסמה.

## עברית, מובייל ונגישות

- הדף מימין לשמאל, עם גופן עברי אמיתי.
- מסך הלקוח נבנה קודם לטלפון, ברוחב 375 פיקסל. מסך הניהול נבנה קודם למחשב. שניהם חייבים לעבוד בשניהם.
- ניגודיות שעוברת את התקן, טקסט חלופי לכל תמונה, תווית לכל שדה, וניווט מלא במקלדת.

## מתי מותר לחרוג

רק כשדרישה מסוג Must ב-PRD לא ניתנת למימוש בסטאק הזה. במקרה כזה:

1. עצור, והצג לי את הדרישה.
2. הסבר במשפט למה הסטאק לא מספיק.
3. הצע את התוספת הקטנה ביותר שפותרת את זה. אל תחליף את כל הסטאק בגלל דרישה אחת.
