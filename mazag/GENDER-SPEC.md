# מפרט גיוד הקופי של מזג

האפליקציה כתובה כולה בפנייה לאישה. צריך שהיא תדע לפנות גם לגבר וגם בלשון כללית.

## איך זה עובד

כל מילה שמשתנה לפי מין נכתבת כשלישייה בתוך הטקסט:

```
{{נקבה|זכר|כללי}}
```

תמיד בסדר הזה, תמיד שלושה חלקים, תמיד עם שני קווים אנכיים.

בזמן טעינת הדף `Mazag.applyGender(document)` מחליף כל שלישייה בצורה הנכונה.
זה כבר עובד ונבדק. **אין צורך לגעת בקוד הזה.**

דוגמאות:

```
{{תרגישי|תרגיש|תרגיש/י}}
{{את|אתה|את/ה}}
{{מקבלת|מקבל|מקבל/ת}}
{{בחרי|בחר|בחר/י}}
{{בטוחה|בטוח|בטוח/ה}}
{{עברת|עברת|עברת}}        ← לא לעשות. ראה את הכלל הבא.
```

## הכלל החשוב ביותר: מילים שאינן משתנות לא מסומנות

בעברית הרבה מילים זהות בשתי הלשונות. **סימון שלהן מנפח את הקובץ ולא נותן כלום.**

**לא לסמן:**

| מילה | למה |
|---|---|
| `שלך` | זהה בזכר ובנקבה |
| `לך`, `אותך`, `איתך`, `עליך`, `ממך`, `בך` | זהות |
| `עברת`, `בחרת`, `קיבלת`, `שמרת`, `ראית` | עבר גוף שני, זהה בשתי הלשונות |
| `את` כמילת מושא | ראה למטה |

**כן לסמן:** פועל בהווה, פועל בציווי, פועל בעתיד, שם תואר, ובינוני.

## המלכודת: שתי המילים "את"

בעברית `את` היא גם כינוי הגוף וגם מילת מושא, ורק אחת מהן משתנה.

```
את מקבלת תחזית אחת          ← כינוי גוף. מסמנים: {{את|אתה|את/ה}} {{מקבלת|מקבל|מקבל/ת}}
אפשר לשנות את המשקולות      ← מילת מושא. לא נוגעים.
ואת מחליטה מה לעשות איתה     ← כינוי גוף. מסמנים.
מדייקים את מזל האופק        ← מילת מושא. לא נוגעים.
```

**מבחן פשוט:** אם אפשר להחליף ב"אתה" והמשפט נשאר תקין, זה כינוי גוף. אם לא, זו מילת מושא.

## מה אסור לגעת בו

- שמות משתנים, פונקציות, מזהים, מחלקות CSS, כתובות, שמות קבצים
- הערות בקוד, כלומר כל מה שבתוך `/* */` או `<!-- -->`
- טקסט שאינו פונה למשתמשת, למשל תיאור של המוצר בגוף שלישי
- מבנה ה-HTML, סדר האלמנטים, רווחים ושורות ריקות

## תכונות HTML

הסימונים עובדים גם בתוך `aria-label`, `placeholder`, `title` ו-`alt`.
אלה נקראות בקול על ידי קורא מסך, ולכן חשוב לא לפספס אותן.

```html
<button aria-label="{{דלגי|דלג|דלג/י}} על ההיכרות">
<input placeholder="{{הזיני|הזן|הזן/י}} תאריך" />
```

## הצורה הכללית

הצורה השלישית היא מה שרואה מי שלא בחרה לשון, וזו ברירת המחדל.
היא נבנית עם קו נטוי אחד:

```
בחר/י     מקבל/ת     את/ה     בטוח/ה     תרגיש/י
```

**כשהצורה הכללית מסורבלת מדי, עדיף לנסח מחדש בלי פנייה אישית:**

```
לפני:  {{את יכולה לשנות|אתה יכול לשנות|את/ה יכול/ה לשנות}} את המשקולות
אחרי:  אפשר לשנות את המשקולות
```

**זה עדיף.** ניסוח שלא צריך מין בכלל טוב משלישייה מכוערת.
תשתמש בזה בכל מקום שבו הניסוח המחודש נשמע טבעי ולא מלאכותי.

## אסור, טכנית

מקף ארוך וחצים אסורים לחלוטין, בכל מקום, גם בעברית וגם באנגלית.

## בדיקה עצמית לפני שמסיימים

1. כל `{{` נסגר ב-`}}`, ובכל שלישייה בדיוק שני קווים אנכיים
2. אין שלישייה שכל שלושת חלקיה זהים
3. הקובץ עדיין תקין: HTML נשאר HTML, JavaScript עדיין מתפרסר
4. לא נותרה פנייה בגוף שני נקבה בלי סימון
