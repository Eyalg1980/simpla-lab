# מזג לאנדרואיד, מדריך הבנייה

הפקודות כאן מוכנות להרצה. הדבר היחיד שחסר הוא דומיין. כשיהיה, כל השלב הזה הוא כעשרים דקות עבודה.

---

## למה בכלל צריך דומיין

TWA היא אפליקציית אנדרואיד שמריצה את האתר במנוע כרום בלי סרגל כתובת. מה שמסיר את סרגל הכתובת הוא **הוכחת בעלות דו כיוונית**: האפליקציה מצהירה על הדומיין, והדומיין מצהיר על האפליקציה, דרך קובץ בשם `assetlinks.json` שיושב תחת `/.well-known/` בשורש שלו.

בלי הצמדה מוצלחת האפליקציה עדיין תעבוד, אבל היא תיפתח עם סרגל כתובת של דפדפן למעלה. זה הורג את התחושה של אפליקציה, וזו הסיבה שאי אפשר לדלג על השלב.

`eyalg1980.github.io` לא יעבוד, כי הקובץ חייב לשבת בשורש הדומיין ולא בתת תיקייה, ואין לך שליטה על שורש `github.io`.

---

## שלב 1: לחבר דומיין לאתר

GitHub Pages תומך בדומיין מותאם ללא עלות. אחרי שהדומיין נרכש:

1. בהגדרות הריפו, Pages, Custom domain, להזין את הדומיין.
2. אצל רשם הדומיין להוסיף רשומות `A` אל `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`, או רשומת `CNAME` אל `eyalg1980.github.io` אם זה תת דומיין.
3. לחכות לאישור, ואז לסמן Enforce HTTPS. TWA מחייב HTTPS תקין.

**החלטה שכדאי לקבל כאן:** האם מזג תשב בשורש הדומיין או בתת תיקייה. TWA הרבה יותר פשוט כשהאפליקציה בשורש, כי אז ה-scope הוא `/` ואין סיכוי לבלבול. ההמלצה היא דומיין ייעודי למזג, שבשורש שלו יושבת האפליקציה.

## שלב 2: לבנות את ה-AAB

```bash
npm install -g @bubblewrap/cli

# החלפת מציין המקום בקובץ ההגדרות
sed -i 's/REPLACE_WITH_DOMAIN/mazag.example.com/g' twa-manifest.json

# הראשונה מבקשת להתקין JDK ו-Android SDK, וזה חד פעמי
bubblewrap init --manifest="https://mazag.example.com/manifest.webmanifest"
# או, כדי להשתמש בהגדרות שכבר מוכנות כאן ולא לענות על השאלון:
bubblewrap build
```

הפלט: `app-release-signed.aab`, וזה הקובץ שנטען לקונסולה.

`bubblewrap init` יבקש ליצור keystore. **הקובץ הזה ואת הסיסמה שלו צריך לגבות במקום בטוח.** אם הם אובדים, אי אפשר יותר להוציא עדכון לאותה אפליקציה, וצריך לפרסם אפליקציה חדשה עם מזהה חבילה אחר. זו התקלה הכי יקרה שאפשר לעשות בשלב הזה.

## שלב 3: להצמיד את הדומיין

אחרי הבנייה, להוציא את טביעת האצבע של מפתח החתימה:

```bash
keytool -list -v -keystore android.keystore -alias mazag | grep SHA256
```

ואז ליצור קובץ בנתיב `/.well-known/assetlinks.json` בשורש האתר:

```json
[{
  "relation": ["delegate_permission/common.handle_all_urls"],
  "target": {
    "namespace": "android_app",
    "package_name": "com.simpla.mazag",
    "sha256_cert_fingerprints": ["<טביעת האצבע מהפקודה למעלה>"]
  }
}]
```

**מלכודת שכדאי לדעת עליה מראש:** אם תבחר ב-Play App Signing, וזו ברירת המחדל ומומלצת, גוגל **מחתימה מחדש** את האפליקציה במפתח שלה. במקרה הזה טביעת האצבע שצריכה להיכנס לקובץ היא זו שמופיעה בקונסולה תחת Setup, App signing, ולא זו שיצאה מה-keystore המקומי. שימוש בטביעה הלא נכונה הוא הסיבה מספר אחת לכך שהאפליקציה נפתחת עם סרגל כתובת, וזה מתגלה רק אחרי ההעלאה.

אימות: `https://<הדומיין>/.well-known/assetlinks.json` צריך להיפתח ולהחזיר `Content-Type: application/json`.

## שלב 4: הקונסולה

1. Google Play Console, חשבון מפתח, תשלום חד פעמי של 25 דולר ואימות זהות. **כדאי להתחיל את זה לפני הכל**, כי האימות לוקח בין יום לשבוע והוא הצוואר בקבוק היחיד בלוח הזמנים.
2. Create app. שם `מזג`, שפת ברירת מחדל עברית, סוג Application, חינם.
3. להעלות את ה-AAB למסלול Internal testing תחילה.
4. למלא את חנות האפליקציות מהחומרים בתיקייה הזו:
   - שם, תיאור קצר, תיאור מלא: `listing-he.md`
   - אייקון: `app-icon-512.png`
   - גרפיקת פיצ'ר: `feature-graphic.png`
   - צילומי מסך: `screenshots/`, שמונה קבצים ב-1080x1920
   - כתובת מדיניות פרטיות: `https://<הדומיין>/privacy.html`
5. שאלון דירוג התוכן, לפי הטבלה ב-`listing-he.md`.
6. טופס בטיחות הנתונים, לפי `data-safety.md`.
7. בדיקה פנימית מגיעה למכשירים תוך שעות. אחרי שהיא עובדת, Production.

## הערה על התזכורת היומית

`enableNotifications` מופעל בהגדרות, וזה נותן לאתר הרשאה להציג התראות דרך העטיפה. אבל התזכורת במזג היא **מקומית**: היא מופעלת כשהאפליקציה פתוחה והשעה הגיעה, ולא על ידי שרת שדוחף הודעה.

המשמעות המעשית: כשהאפליקציה סגורה לגמרי, התזכורת לא תגיע. זה כתוב במסך ההתראות ובמדיניות הפרטיות, וזה בסדר לשחרור ראשון. תזכורת אמיתית שעובדת כשהאפליקציה סגורה דורשת שרת Push, וזו החלטת מוצר נפרדת שכרוכה גם בשינוי מדיניות הפרטיות, כי אז נשמר אצלנו אסימון התראות של המכשיר.
