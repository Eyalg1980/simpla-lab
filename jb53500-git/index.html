Git צעד אחר צעד מהטרמינל הראשון לקומיט הראשון

עושים את זה פעם אחת ביד, כדי להבין מה קורה מתחת. מכאן והלאה Claude Code עושה את זה בשבילכם במשפט אחד.

בחרו למעלה Windows או Mac, והמדריך יציג רק את מה שרלוונטי למחשב שלכם.

ארבע התקנות, כחצי שעהלא מתקינים בכיתה. התקנה שנכשלת באמצע השיעור עולה בלוק שלם

  1. Git: מורידים מ-git-scm.com, ובהתקנה לוחצים Next בכל המסכים. ברירות המחדל מתאימות
  2. Git: פותחים Terminal, מקלידים git --version ולוחצים Enter. אם Git לא מותקן, נפתח חלון שמציע להתקין Command Line Tools. לוחצים Install ומחכים
  3. Obsidian: מ-obsidian.md. בו קוראים את קבצי ה-MD של הפרויקט
  4. GitHub Desktop: מ-desktop.github.com
  5. חשבון GitHub: ב-github.com/signup, עם הג׳ימייל של הקורס
בכיתה: הטרמינל
1

פותחים טרמינל

לוחצים על Start, מקלידים Terminal ולוחצים Enter. במחשב ישן יותר זה ייקרא PowerShell. שניהם עובדים.

לוחצים Cmd ורווח יחד, מקלידים Terminal ולוחצים Enter.

חלון עם שורה אחת וסמן מהבהב. כאן כותבים פקודה, לוחצים Enter, והמחשב עונה.

2

בודקים ש-Git מותקן

git --version

אמור להופיע: משהו כמו git version 2.47.1. המספר המדויק לא משנה.

3

ארבע פקודות תנועהאיפה אני, מה יש פה, להיכנס, לצאת

pwd
ls
cd Documents
cd ..
  • pwd מראה באיזו תיקייה אתם עכשיו
  • ls מציג מה יש בתיקייה
  • cd ושם של תיקייה נכנס אליה, ו-cd .. יוצא תיקייה אחת למעלה
  • mkdir ושם יוצר תיקייה חדשה
שם עם רווח? עוטפים במרכאות: cd "My Project". ובגלל זה שמות פרויקט באנגלית ובלי רווחים.
בכיתה: Git
4

מציגים את עצמכם ל-Gitפעם אחת בכל מחשב. Git מצמיד את השם הזה לכל צילום

מחליפים את השם ואת המייל בשלכם. השם באנגלית, והמייל הוא הג׳ימייל של הקורס:

git config --global user.name "Your Name"
git config --global user.email "your.course@gmail.com"
git config --global init.defaultBranch main

ובודקים:

git config --global --list

אמור להופיע: שלוש שורות, עם השם, המייל ו-init.defaultbranch=main.

5

נכנסים לתיקיית הפרויקטהתיקייה עם שבעת מסמכי האפיון

הדרך הקצרה: פותחים את התיקייה בסייר הקבצים, לוחצים עליה בכפתור ימני, ובוחרים Open in Terminal. הטרמינל נפתח ישר בתוכה.

הדרך הקצרה: מקלידים cd ורווח, גוררים את התיקייה מה-Finder לתוך חלון הטרמינל, ולוחצים Enter.

בודקים שאתם במקום הנכון:

pwd
ls

אמור להופיע: הנתיב מסתיים בשם הפרויקט, ו-ls מציג את PRD.md ואת שאר המסמכים.

6

הופכים את התיקייה לריפו

git init

אמור להופיע: Initialized empty Git repository. נוצרה תיקייה נסתרת בשם .git, ושם Git שומר את כל הצילומים. לא נוגעים בה.

7

מה Git רואההפקודה שמריצים הכי הרבה

git status

אמור להופיע: רשימת קבצים באדום, תחת Untracked files. אדום אומר ש-Git רואה אותם, אבל עוד לא ביקשתם לצלם אותם.

8

מכניסים לפריים, ומצלמים

שלב א, add: הנקודה אומרת "את כל מה שבתיקייה".

git add .
git status

אמור להופיע: אותם קבצים, עכשיו בירוק. הם בפריים.

שלב ב, commit: הצילום עצמו, עם משפט שמסביר מה בו.

git commit -m "Spec documents, first version"

ורואים את ההיסטוריה:

git log --oneline

אמור להופיע: שורה אחת, עם קוד קצר ואחריו המשפט שכתבתם.

9

עוד סיבוב, כדי שזה יישבמשנים, בודקים, מוסיפים, מצלמים

פותחים את PRD.md ב-Obsidian, משנים משהו קטן ושומרים. חוזרים לטרמינל:

git status
git add .
git commit -m "PRD: updated out of scope"
git log --oneline

אמור להופיע: קודם modified: PRD.md, ובסוף שתי שורות בהיסטוריה. זה כל הסוד: שינוי, status, add, commit.

בכיתה: לאינטרנט
10

מעלים את הריפו ל-GitHub, בלי פקודות

  1. פותחים את GitHub Desktop ומתחברים לחשבון GitHub
  2. File, ואז Add local repository, ובוחרים את תיקיית הפרויקט
  3. לוחצים Publish repository
  4. נכנסים ל-github.com ורואים את הקבצים שם
ציבורי או פרטי? כדי שהאתר יעלה לאוויר בחינם ב-GitHub Pages, הריפו צריך להיות ציבורי. לכן אף פעם לא שמים בו סיסמה או מפתח API.
כשמשהו לא עובד
+'git' is not recognized
סוגרים את הטרמינל ופותחים חדש. הטרמינל שהיה פתוח בזמן ההתקנה לא מכיר את Git. אם זה עדיין קורה, מתקינים שוב עם ברירות המחדל.
+xcrun: error: invalid active developer path
חסרים כלי הפיתוח של אפל. מריצים xcode-select --install, מאשרים בחלון שנפתח, ומחכים כמה דקות.
+Author identity unknown, או Please tell me who you are
דילגתם על שלב 4. מריצים את שתי פקודות ה-config, ומנסים שוב את ה-commit.
+fatal: not a git repository
אתם לא בתיקיית הפרויקט. pwd כדי לראות איפה אתם, ו-cd כדי להגיע לתיקייה הנכונה.
+נפתח מסך מוזר אחרי commit, ואי אפשר לצאת
שכחתם את -m והמשפט, ו-Git פתח עורך. לוחצים Esc, מקלידים :q! ולוחצים Enter. ואז מריצים שוב את ה-commit, הפעם עם -m "...".
+nothing to commit, working tree clean
זו לא שגיאה. אין שום שינוי מאז הצילום האחרון, אז אין מה לצלם.
+שמות קבצים בעברית נראים כמו ג׳יבריש
זה רק באופן שבו הטרמינל מציג אותם. הקבצים בסדר. בכל זאת, שמות קבצים של הפרויקט באנגלית ובלי רווחים חוסכים תקלות בהמשך, במיוחד כשהאתר עולה לשרת.
