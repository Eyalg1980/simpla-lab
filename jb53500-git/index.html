פותחים חשבון GitHubעם הג׳ימייל של הקורס

  1. נכנסים ל-github.com/signup, ונרשמים עם הג׳ימייל של הקורס
  2. שם המשתמש באנגלית, בלי רווחים. הוא יופיע בכתובת של האתר שלכם
  3. מאשרים את המייל ש-GitHub שולח

אמור להופיע: אתם מחוברים ב-github.com, עם תמונת פרופיל בפינה העליונה.

מתקינים GitHub Desktop, ומתחבריםדרכו נעלה את הפרויקט לאינטרנט, בלי פקודות

  1. מורידים מ-desktop.github.com, ומתקינים
  2. בפתיחה הראשונה לוחצים Sign in to GitHub.com, ומאשרים בדפדפן שנפתח
  3. במסך Configure Git משאירים את הבחירה כמו שהיא, ולוחצים Finish

אמור להופיע: מסך הפתיחה של GitHub Desktop, מחובר לחשבון שלכם.

סיימתם כש: git --version מציג מספר גרסה, ו-GitHub Desktop פתוח ומחובר לחשבון שלכם.

ארבע פקודות תנועהאיפה אני, מה יש פה, להיכנס, לצאת

pwd
ls
cd Downloads
cd ..
  • pwd מראה באיזו תיקייה אתם עכשיו
  • ls מציג מה יש בתיקייה
  • cd ושם של תיקייה נכנס אליה, ו-cd .. יוצא תיקייה אחת למעלה
  • mkdir ושם יוצר תיקייה חדשה
שם עם רווח? עוטפים במרכאות: cd "My Project". ובגלל זה שמות פרויקט באנגלית ובלי רווחים.

4

מציגים את עצמכם ל-Gitפעם אחת בכל מחשב. Git מצמיד את השם הזה לכל צילום

מחליפים את השם ואת המייל בשלכם. השם באנגלית, והמייל הוא הג׳ימייל של הקורס:

git config --global user.name "Your Name"
git config --global user.email "your.course@gmail.com"
git config --global init.defaultBranch main

ובודקים:

git config --global --list

אמור להופיע: שלוש שורות, עם השם, המייל ו-init.defaultbranch=main.

מה Git רואההפקודה שמריצים הכי הרבה

git status

אמור להופיע: רשימת קבצים באדום, תחת Untracked files. אדום אומר ש-Git רואה אותם, אבל עוד לא ביקשתם לצלם אותם.

8

מכניסים לפריים, ומצלמים

שלב א, add: הנקודה אומרת "את כל מה שבתיקייה".

git add .
git status

אמור להופיע: אותם קבצים, עכשיו בירוק. הם בפריים.

שלב ב, commit: הצילום עצמו, עם משפט שמסביר מה בו.

git commit -m "Spec documents, first version"

ורואים את ההיסטוריה:

git log --oneline

אמור להופיע: שורה אחת, עם קוד קצר ואחריו המשפט שכתבתם.

בתפריט העליון בוחרים File, ואז Options, ואז Accounts.בתפריט העליון בוחרים GitHub Desktop, ואז Settings או Preferences, ואז Accounts. לוחצים Sign in ליד GitHub.com, ומאשרים בדפדפן.
+xcrun: error: invalid active developer path
חסרים כלי הפיתוח של אפל. מריצים xcode-select --install, מאשרים בחלון שנפתח, ומחכים כמה דקות.

דילגתם על שלב 4. מריצים את שתי פקודות ה-config, ומנסים שוב את ה-commit. בחלק ב: כותבים ל-Claude את השם והמייל, ומבקשים שיגדיר אותם.
+Claude אומר ש-Git לא מותקן, אבל התקנתי
Claude Desktop היה פתוח בזמן ההתקנה, ולכן הוא עדיין לא מכיר את Git. סוגרים אותו לגמרי, פותחים מחדש, ושולחים שוב את הבקשה.
+אין לי לשונית Code, או שמבקשים ממני לשדרג

+fatal: not a git repository
אתם לא בתיקיית הפרויקט. pwd כדי לראות איפה אתם, ו-cd כדי להגיע לתיקייה הנכונה.
+נפתח מסך מוזר אחרי commit, ואי אפשר לצאת
שכחתם את -m והמשפט, ו-Git פתח עורך. לוחצים Esc, מקלידים :q! ולוחצים Enter. ואז מריצים שוב את ה-commit, הפעם עם -m "...".

זו לא שגיאה. אין שום שינוי מאז הצילום האחרון, אז אין מה לצלם.
