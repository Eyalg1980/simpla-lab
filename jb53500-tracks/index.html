React הממשק

ספרייה לבניית ממשקים מקומפוננטות.

מה זה
כל חלק במסך הוא רכיב, כמו קומפוננטה בפיגמה: כרטיס, כפתור, רשימה. בונים אותו פעם אחת, ומשתמשים בו בכל מקום.
למה
במוצר עם הרבה מסכים, ומידע שעובר ביניהם, זה שומר על סדר. בלי React הקוד נוטה להתפזר.

Vite כלי הבנייה

המטבח של הפרויקט. מבטאים "ויט".

בפיתוח
הפקודה npm run dev פותחת את האתר במחשב, וכל שמירה מופיעה מיד בדפדפן.
לפני פריסה
הפקודה npm run build אורזת את הפרויקט לתיקייה dist, עם קבצים רגילים שהדפדפן מבין. Vercel מריץ את זה לבד בכל דחיפה.
צריך
Node.js במחשב, בגרסה 20.19 ומעלה או 22.12 ומעלה.

TypeScript שכבת בדיקה

טעות כמו שם שדה שגוי נתפסת לפני שהקוד רץ, ולא אצל המשתמש. Claude מריץ את הבדיקה ומתקן את עצמו.
אתם
לא צריכים לכתוב TypeScript. צריך לקרוא את הקוד, ולוודא שהבנייה עוברת.

  1. הקובץ. מורידים את course-stack-plus.md, ושמים אותו בתיקיית המוצר ליד course-stack.md.

  4. מסך אחרי מסך. כל Milestone מעביר מסך אחד, באותו מראה כמו ב-DESIGN.md. בלי פיצ'רים חדשים בזמן המעבר.
